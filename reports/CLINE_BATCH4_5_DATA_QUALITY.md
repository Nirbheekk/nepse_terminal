# Batch 4.5 — Data Quality

## Validation
- Opening date not after closing date (public issues).
- Nonnegative prices.
- Valid event types.
- Valid meeting types.
- Consistent issuer symbols.
- Duplicate detection (idempotent upserts).
- Missing source documents flagged.

## Status values
VERIFIED/PROVISIONAL/UNVERIFIED/REVIEW_REQUIRED/REJECTED preserved.
