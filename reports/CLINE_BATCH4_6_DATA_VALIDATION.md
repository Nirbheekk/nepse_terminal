# Batch 4.6 — Data Validation

## Balance sheet validation
Assets = Liabilities + Equity (exact by default; tolerance configurable).

## Cash flow validation
Documented; implemented as tolerance-aware helper where data available.

## Cross-period validation
Duplicate periods, conflicting figures, unit changes, restatements, missing comparatives, quarter/YTD confusion flags.

## Source validation
Every fact references report; every report references source; unverified facts not promoted.
